## Minelab Equinox Detector Reset

Performing a FULL Factory RESET on your Minelab Equinox 900 and 700 metal detector can be necessary for several reasons, and these are for the Equinox 900, 800, 700 and 600 detectors

<strong>Technical Issues:</strong> If the device is experiencing software glitches, errors, or unusual behaviour, a factory reset can often resolve these issues by restoring the Equinox's default settings.

<strong>Customisation:</strong> If you've made numerous adjustments to your Minelab Equinox settings and want to revert to the original factory settings, a reset allows you to start afresh.

<strong>Sale or Transfer:</strong> Resetting the detector to its factory settings might be necessary if you're selling or passing it on to someone else, ensuring that the new user begins with the default configurations.

### Resetting a single search profile on your Minelab Equinox

Can be advantageous for specific reasons:

<strong>Restore Specific PROFILE Defaults:</strong> If you've made extensive changes in one profile and you really are not sure what the heck you have done but wish to revert only specific settings to their original defaults, resetting that profile individually helps without affecting other customised profiles.

<strong>Testing and Comparison:</strong> Resetting one profile allows you to experiment with different settings while keeping others intact. This is helpful if you want to compare the performance of various configurations without losing all your customised profiles.

<strong>Fine-Tuning:</strong> You might want to reset one profile to fine-tune or optimise specific settings for a particular type of search (e.g., changing TONES or discrimination patterns for different terrains or targets).

<strong>Target-Specific Settings:</strong> Resetting a single profile can be useful if you've tailored settings for a specific type of target (like coins, relics, or gold) and want to refine those settings while keeping other profiles unchanged.

Remember, Resetting a single profile allows you to make targeted adjustments without affecting the entirety of your Minelab Equinox settings. It's a more controlled way to manage changes and maintain multiple configurations for various detecting scenarios.
