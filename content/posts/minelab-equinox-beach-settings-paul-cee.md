## Beach settings for the Minelab Equinox 800 50 Tones

![Minelab Equinox 800 control box on the Basic Detect screen after switching on](/img/PB280315.webp "Starting point: the Basic Detect screen when the Equinox is turned on")

Initial turning on you have the Basic Detect screen

![deep EQUINOX settings](/img/PB280315_alliron.webp "Red arrow marks the horseshoe button used to select All Metal mode")

Press the HORSE SHOE Button to select ALL METAL MODE

![Red arrow on the Detect button of a Minelab Equinox 800 to choose Beach 1 mode](/img/PB280315_selectmode.webp "Pressing Detect to select the Beach 1 search mode")

Press the DETECT button to select BEACH 1

![Red arrow pointing at the Function button on the Minelab Equinox 800 keypad](/img/PB280315_function.webp "The Function button steps through the settings, starting with Noise Cancel")

Press the FUNCTION Button to Select Noise Cancel

![Minelab Equinox 800 Noise Cancel screen showing a reading of minus 4](/img/PB280317_nywhvgky.webp "Noise Cancel screen, ready to be confirmed with Accept/Reject")

Press The Accept Reject Button to confirm noise cancel ![Minelab Equinox settings](/img/PB280317_select.webp "Red arrow on the Accept/Reject button to confirm Noise Cancel")

![setting up a Minelab Equinox](/img/PB280318.webp "Ground Balance screen reached by pressing Function again")

Press Again the FUNCTION BUTTON for Ground Balance

Use the PLUS &amp; Minus Buttons while SLOWLY Pumping the Coil above ground with targets beneath the coil!!! use the plus and minus buttons to adjust ![Equinox 800 ground balance screen at 6 with a red arrow on the plus/minus button](/img/PB280318_gb.webp "Ground balance can be set by hand or switched to Ground Tracking")

or Select the plus minus button for GROUND TRACKING

![Minelab Equinox 800 volume adjust screen showing 25 with a finger on the keypad](/img/PB280319.webp "Volume Adjust for the 50 Tones profile, set with plus and minus")

Next is VOLUME ADJUST for 50 Tones( I USE MAX VOLUME FOR MAIN TONES)

![Equinox 800 noise cancel screen at minus 4 before holding Function for the second screen](/img/PB280317.webp "Hold the Function button to open the second screen of settings")

PRESS AND HOLD FUNCTION BUTTON to access 2nd screen mode ![Minelab Equinox 800 Detect screen with a red arrow on the Function button in Multi mode](/img/PB280315_function_unnua97i.webp "Press and hold Function to reach the second settings screen")

![Minelab Equinox 800 tone settings screen showing tone 1 volume at 16](/img/PB280320.webp "Iron tone volume kept low so the non-ferrous tones stand out")

Tone 1 Volume (IRON) is set to 16 to allow quiet hearing of the non ferous tone

![Equinox 800 screen with the tone volume at 25 and tone 2 shown below](/img/PB280322.webp "Tone 2 volume set at 25 on the 50 Tones profile")

Tone 2 is set at 25

Press the FUNCTION BUTTON Again to access the SIGNAL TONES Function

![Minelab Equinox 800 Signal Tones screen for tone 1 with a finger on the keypad](/img/PB280332.webp "Signal Tones: choose the tone, then plus/minus moves on to tone 2")

Set The desired TONE. THEN PRESS THE PLUS/MINUS BUTTON to access tones 2![Equinox 800 Signal Tones screen with a red arrow on the plus/minus button](/img/PB280332_A.webp "Plus/minus switches from tone 1 to the tone 2 selection") Tone 2 selection is now available select the desired tone ![Equinox 800 display showing tone 2 selected beside the volume value of 25](/img/PB280331.webp "Picking the tone 2 pitch before moving on to Recovery Speed")

Press the FUNCTION BUTTON To Access RECOVERY SPEED and IRON BIAS SETTING

![Equinox 800 Recovery Speed screen set to 4 with a red arrow on the minus button](/img/PB280329_A.webp "Recovery Speed 4 suits deep iron on the beach with a slow swing")

I use RECOVERY SPEED of 4 as the beaches have deep iron but with a slow swing speed this is the best setting i have found..

Press and hold the FUNCTION BUTTON to access the IRON BIAS setting..

(This is the Setting there is so much debate about whether it is set at zero or higher)

[![Minelab Equinox 800 Iron Bias screen showing an FE value of 3](/img/PB280328.webp "Iron Bias set at 3, the setting detectorists debate most")](https://youtu.be/o6n_H_onH3o)

I personally use this set at 3

Press the DETECT/PINPOINT button to return to the main Detect SCREEN ![Red arrow on the Detect/Pinpoint button of the Equinox 800 control box](/img/PB280316_A.webp "Detect/Pinpoint takes you back to the main Detect screen")

Finally set the Sensitivity to suit.. some people tend to run The EQUINOX VERY HOT (high sensitivity) and if you are just learning the detector this will seriously frustrate you as it is very noisy, adjust using the PLUS/Minus buttons ![Equinox 800 screen reading 6 with a finger over the Detect/Pinpoint button](/img/PB280318_gb_02em57go.webp "Final settings, tuned over the months using the stock coil") usually between 19 and 24 i have found to be the most stable but as beach conditions can vary greatly from beach to beach then so can this value..

These are the settings i have tuned over the months using the STOCK COIL.

Setting for the 15" coil still in testing but i will update when i have good stable results
