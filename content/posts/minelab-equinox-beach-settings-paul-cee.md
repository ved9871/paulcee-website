## Beach settings for the Minelab Equinox 800 50 Tones

![Beach Settings1](/img/PB280315.webp "small")

Initial turning on you have the Basic Detect screen

![deep nox settings](/img/PB280315_alliron.webp "small")

Press the HORSE SHOE Button to select ALL METAL MODE

![paul cee settings](/img/PB280315_selectmode.webp "small")

Press the DETECT button to select BEACH 1

![equinox detect screen](/img/PB280315_function.webp "small")

Press the FUNCTION Button to Select Noise Cancel

![nox screen](/img/PB280317_nywhvgky.webp "small")

Press The Accept Reject Button to confirm noise canel ![Equinox settings](/img/PB280317_select.webp "small")

![setting up equinox](/img/PB280318.webp "small")

### Press Again the FUNCTION BUTTON for Ground Balance

Use the PLUS &amp; Minus Buttons while SLOWLY Pumping the Coil above ground with targets beneath the coil!!! use the plus and minus buttons to adjust ![setting equinox sensitivity](/img/PB280318_gb.webp "small")

or Select the plus minus button for GROUND TRACKING

![tone adjust](/img/PB280319.webp "small")

Next is VOLUME ADJUST for 50 Tones( I USE MAX VOLUME FOR MAIN TONES)

![minelab Equinox 800 beach settings](/img/PB280317.webp "small")

PRESS AND HOLD FUNCTION BUTTON to access 2nd screen mode ![nox function button](/img/PB280315_function_unnua97i.webp "small")

![tone settings](/img/PB280320.webp "small")

Tone 1 Volume (IRON) is set to 16 to allow quiet hearing of the non ferous tone

![equinox 50 tones](/img/PB280322.webp "small")

Tone 2 is set at 25

Press the FUNCTION BUTTON Again to access the SIGNAL TONES Function

![equinox tone volume](/img/PB280332.webp "small")

Set The desired TONE. THEN PRESS THE PLUS/MINUS BUTTON to access tones 2![setting for tones](/img/PB280332_A.webp "small") Tone 2 selection is now available select the desired tone ![minelab Equinox 800 beach settings](/img/PB280331.webp "small")

Press the FUNCTION BUTTON To Access RECOVERY SPEED and IRON BIAS SETTING

![minelab Equinox 800 beach settings](/img/PB280329_A.webp "small")

I use RECOVERY SPEED of 4 as the beaches have deep iron but with a slow swing speed this is the best setting i have found..

Press and hold the FUNCTION BUTTON to access the IRON BIAS setting..

(This is the Setting there is so much debate about whether it is set at zero or higher)

![Equinox iron bias](/img/PB280328.webp "small")

I personally use this set at 3

Press the DETECT/PINPOINT button to return to the main Detect SCREEN ![equinox pinpoint button](/img/PB280316_A.webp "small")

Finally set the Sensitivity to suit.. some people tend to run The EQUINOX VERY HOT (high sensitivity) and if you are just learning the detector this will seriously frustrate you as it is very noisy, adjust using the PLUS/Minus buttons ![equinox 800 sensitivity](/img/PB280318_gb_02em57go.webp "small") usually between 19 and 24 i have found to be the most stable but as beach conditions can vary greatly from beach to beach then so can this value..

These are the settings i have tuned over the months using the STOCK COIL.

Setting for the 15" coil still in testing but i will update when i have good stable results
