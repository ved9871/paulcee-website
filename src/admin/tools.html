Site tools

Backups, undo, and who can edit. Each button opens in a new tab, so this page stays put. The GitHub ones need you signed in to GitHub.

Edit the site

Open the editor View the site

Every save in the editor publishes within a few minutes. Posts marked Draft, and posts dated in the future, stay hidden until you untick Draft or the date arrives.

Backups

A full copy of all pages, posts, events, products and images is made every Sunday night. You can also make one whenever you like.

Download a backup Make a backup now

Each backup is a zip file named by date. On the "Make a backup now" page, press Run workflow, then Run workflow again. The newest 12 backups are kept.

Restore a backup

Puts all content and images back to how they were in a chosen backup. Nothing is lost: the state before the restore stays in the history, so you can restore a newer backup afterwards.

Restore a backup
  1. Press Run workflow.
  2. Type the backup name from the Releases page, for example backup-2026-10-04. You can also paste a link to a backup zip you downloaded and re-uploaded somewhere.
  3. Press Run workflow. The site rebuilds in a few minutes.

Who can edit

Editors sign in with a free GitHub account. To let someone in, add them as a collaborator with the Write role. To remove someone, take them off the same page.

Invite or remove an editor

Press Add people, enter their GitHub username or email, choose Write. They get an email invitation; once accepted they can sign in at the editor. Only the site owner can change this list.
